## 新模式设计

- `Subject`
  - `Asset`：Block / Human。
  - `Reset`：重置当前 Subject 的 scale 或 transform。
- `Prop`
  - `Asset`：Box / Chair / Table / Sofa。
  - `Reset`：重置当前 Prop 的 scale 或 transform。
  - 后续可选 `Duplicate`。
- `Frame`
  - `Frame`：2.39:1 / 16:9 / 4:3 / 1:1 / 9:16。
  - `Lens`：24mm / 35mm / 50mm / 85mm。
  - `Shot`：Wide Shot / Medium Shot / Close-Up / Low Angle。
  - `Guides`：构图线开关。
- `Light`
  - `Direction`：Key Left / Rim Right / Front Soft / Top / Low Side。
  - `Color`：3200K / 4500K / 5600K / 7000K。
  - `Intensity`：短滑杆。
  - `Spread`：短滑杆。
- 全局：
  - `Look`：Capture 风格 / 滤镜。
  - `Lookbook`：Studio / 历史结果入口。
  - `Reset Scene`：次级全局操作，避免误触。

## 修改原因

- 现在 Subject / Prop 已支持手势缩放，主界面继续保留 Size slider 会增加视觉密度，也会削弱 AR 直接操控感。
- Apple Camera 的核心体验是“取景优先 + 快门居中 + 模式轻量切换”，比大面积参数面板更适合 SceneZero 的 AR Capture 主界面。
- `Shot` 与 `Frame / Lens` 都属于镜头语言，应放在同一组里。
- `Look` 影响最终 Capture 风格和后处理，不应跟某个空间对象绑定。
