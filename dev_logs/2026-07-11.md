## 今日完成

- 使用 `ui-ux-pro-max` 评估移动端创作工具的主题色策略。
- 讨论并确认 iOS app 更常见的主题色结构：
  - 一个主品牌色承担大部分导航、选中态、CTA 和核心操作。
  - 少量辅助信息色用于结构化内容、metadata、说明性区域。
  - 功能色仅用于错误、收藏、警告等语义状态。
- 曾短暂尝试 `Projector Amber + Storyboard Indigo` 双色方案。
- 根据视觉反馈，将双主色收敛为：
  - 绿色作为 SceneZero 的唯一主色。
  - Indigo 作为结构化信息辅助色。
- 将 Profile 页面也接入统一主题系统，避免仍使用系统 `accentColor`。
- 保留此前 HIG 改动中的语义主题文件 `SceneZeroTheme.swift`，让后续视觉调整集中在 token 层。

## 关键实现

- 涉及文件：
  - `SceneZero/SceneZero/Views/SceneZeroTheme.swift`
  - `SceneZero/SceneZero/Views/RootTabView.swift`
  - `SceneZero/SceneZero/Views/MainView.swift`
  - `SceneZero/SceneZero/Views/LookbookView.swift`
  - `SceneZero/SceneZero/Views/ProfileView.swift`
- 核心逻辑：
  - 新增并使用语义色 token：
    - `accent`：SceneZero 主品牌色，当前为绿色。
    - `accentSoft`：主品牌色的浅色背景，用于 pill、tab selected background、标签底色。
    - `infoAccent`：辅助信息色，当前为 Indigo。
    - `infoAccentSoft`：辅助信息色浅背景。
    - `promptAccent`：结构化提示词标题色，映射到 `infoAccent`。
  - 绿色主色职责：
    - Bottom tab 选中态。
    - Capture 工具当前项。
    - 保存到灵感库主按钮。
    - 灵感库隐私 pill、board tag、保存位置 tag。
    - Profile 统计、开关 tint、主要设置项。
  - Indigo 辅助色职责：
    - Capture review 中的来源 / metadata 信息。
    - `结构化提示词` 标题。
    - Reference detail 中的 prompt / metadata 辅助动作。
    - Profile 中少量信息类入口，例如 `关于 SceneZero`。
- 重要参数或 API：
  - 主色：
    - `Color(red: 0.31, green: 0.52, blue: 0.36)`
  - 主色浅背景：
    - `Color(red: 0.83, green: 0.90, blue: 0.78)`
  - 信息辅助色：
    - `Color(red: 0.31, green: 0.27, blue: 0.90)`
  - 信息辅助浅背景：
    - `Color(red: 0.90, green: 0.90, blue: 1.00)`
  - `ProfileView` 中使用 `.tint(SceneZeroTheme.accent)` 统一系统交互强调色。
  - `RootTabView` 中 tab selected foreground 与 background 改回 `accent / accentSoft`。

## 遇到的问题

- 问题描述：
  - Amber + Indigo 同时作为主色时，视觉上像两个品牌系统叠在一起。
  - Profile 页面最初仍使用 `Color.accentColor` 和零散系统色，没有接入新主题。
- 原因分析：
  - iOS app 通常通过一个强主色建立识别，第二色更适合作为内容分区或信息辅助，而不是平级品牌色。
  - Profile 页面属于设置 / 账户类页面，若颜色体系不同，会破坏全局一致性。
- 当前解决方案：
  - 将绿色恢复为唯一主品牌色。
  - 将 Indigo 重命名为 `infoAccent`，从语义上限制其使用场景。
  - Profile 页面头像、统计项、Toggle、设置项、tint 全部接入 `SceneZeroTheme`。
- 是否遗留风险：
  - 当前颜色仍使用代码内 `Color(red:green:blue:)`，后续如果要完善暗黑模式和设计交付，可以迁移到 Asset Catalog color set。
  - `infoAccent` 的使用需要继续克制，避免后续新组件又把它当第二主色使用。
