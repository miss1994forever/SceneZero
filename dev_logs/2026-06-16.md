## 今日完成

- 新增 4 个轻量 `.usdz` 白模资产：
  - `Human.usdz`
  - `Chair.usdz`
  - `Table.usdz`
  - `Sofa.usdz`
- 资产放置位置：
  - `SceneZero/SceneZero/Assets3D/`
- 资产特征：
  - 使用低面数 USD primitives 生成。
  - 无复杂贴图、无动画、无外部依赖。
  - 文件体积极小，适合课程演示和加载管线验证。
- 清理生成中间文件：
  - `.usda` 源文件仅用于生成 `.usdz`，最终未保留在 app bundle 中。
- 修复 `.usdz` 模型放置后可能漂浮的问题：
  - 加载 bundle 模型后读取 `visualBounds(relativeTo:)`。
  - 根据模型自身 bounds 的 `min.y` 自动把模型底部对齐到 proxy 的地面线。
  - 该修正不依赖当前 4 个极简白模的固定尺寸，后续替换更专业 `.usdz` 时也能继续生效。
- 调整底部 UI 交互：
  - `Subject / Prop / Frame / Light` 模式滑动选择器的固定选择位改为透明描边，不再使用带阴影的玻璃胶囊底座。
  - 当前模式的具体功能按钮始终全部显示。
  - 功能按钮在窄屏下自动排列为 2 列，宽屏下尽量一行显示。
  - 点击某个功能按钮后，不再使用固定长度横向滑动胶囊。
  - 改为在垂直方向展开参数面板，直接显示所有可选参数按钮或对应滑杆。
- 进一步调整主拍摄 UI 的空间位置：
  - 横屏和竖屏都将 `Capture`、模式选择器、当前模式调节按钮放到屏幕右侧。
  - 移除主控制区对底部栏的依赖，避免竖屏压缩 AR 画面、横屏遮挡画面下半部分。
  - `Subject / Prop / Frame / Light` 模式选择器改为竖向滑动，固定选择位仍保持透明描边。
  - 右侧控制列按屏幕尺寸限制宽度和高度，iPhone 与 iPad 共用同一套布局策略。
- 修正右侧控制列的层级与排列：
  - `Capture` 快门按钮固定在右侧垂直中线，不再受上方参数面板高度影响。
  - 当前模式调节按钮改为真正的纵向排列，不再由 `LazyVGrid` 按宽度自动铺成横排。
  - 调节按钮放在右上区域，模式选择器放在快门下方，避免三组控件互相挤压。
- 继续 Apple Camera 化右侧控制 UI：
  - 未选中的 `Subject / Prop / Frame / Light` 模式图标改为白色半透明显示，提升在 AR 暗色/复杂画面上的可读性。
  - 模式选择图标从 38pt 增大到 44pt，固定选择位从 50pt 增大到 56pt。
  - 当前模式调节按钮从 38pt 增大到 44pt，图标字号从 15pt 增大到 17pt，触控面积更接近 iOS 常见 44pt 标准。
  - 删除调节按钮列下方的整组玻璃胶囊底层，只保留每个圆形按钮自身的玻璃样式，降低视觉密度。
  - 将 `Capture` 与下方模式选择器的间距改为固定 18pt，减少横竖屏切换时的视觉漂移。
  - 点击调节按钮后，不再在按钮上方出现独立浮窗。
  - 新增按钮左侧内联参数胶囊栏：点击哪个调节按钮，就在该按钮左侧展开对应的选项或滑杆。
  - `Asset / Frame / Lens / Shot / Direction / Color` 使用横向胶囊选项；`Intensity / Spread` 使用内联百分比 + 短滑杆。
- 缩小右侧调节按钮与 `Capture` 快门之间的距离：
  - 调节按钮列不再固定贴近右上角。
  - 改为按按钮列高度计算位置，让按钮列底部贴近快门上缘。
  - 上方调节按钮与快门的默认间距统一为 18pt，和下方模式选择器与快门的间距保持一致。
  - 横屏高度不足时保留顶部保护距离，避免按钮与状态栏/顶部状态胶囊重叠。
- 微调右侧控件的对齐和间距：
  - 修正调节按钮列圆心相对 `Capture` 和模式选择器偏右的问题。
  - 调节按钮列现在使用 `(shutterSize - adjustmentButtonSize) / 2` 做右侧补偿，与快门圆心对齐。
  - 上方调节按钮与快门的间距从 18pt 增大到 30pt，让右侧控制列呼吸感更好。
  - 下方模式选择器与快门仍保持 18pt，维持相机式模式切换的紧凑感。
- 确定取景框与输出图的产品规则：
  - `Frame Is Output`：取景框线代表最终保存到 Lookbook 的参考图边界，不再只是 UI 辅助线。
  - `Frame Stays Stable`：切换模式、展开调节胶囊、调节参数时，取景框大小和位置保持稳定。
  - `Persistent Controls Avoid Frame`：常驻控件如 `Capture`、模式选择器、默认调节按钮列应尽量避开取景框。
  - `Temporary Controls May Overlay Frame`：短时出现的参数胶囊可以临时向左延展并覆盖取景框线，但不改变取景框本身。
  - `Capture Crops To Frame`：保存到 Lookbook 的图片应裁切到取景框范围，不包含右侧 UI 控件或全屏遮罩。
  - 点击 `Capture` 前应自动收起临时参数胶囊，让界面回到构图态。
- 实施取景框与输出图一致性改造：
  - 新增 `FramingSafeInsets`，用于描述顶部、底部、左侧和右侧常驻 UI 的取景框安全区。
  - `FramingGeometry.frameRect` 支持传入 `contentInsets`，实时取景框和保存裁切共用同一套 frame rect 计算。
  - `MainView` 新增 `framingContentInsets`，为右侧常驻控制区预留稳定安全区；`activeAdjustment` 不参与计算，因此展开临时胶囊不会改变取景框。
  - `FramingOverlayView` 接入 `contentInsets`，取景框线稳定避开右侧常驻按钮区。
  - 点击 `Capture` 时先调用 `dismissAdjustment()`，自动收起临时参数胶囊。
  - `FramingOverlayService.applyOverlay` 新增按取景框裁切输出的路径，Lookbook 保存图现在裁切到取景框范围。
  - 裁切后不再保留全屏黑色遮罩；若开启 composition guides，则在裁切图上保留轻量三分线参考。
- 修正 Prompt / Lookbook 的灯光记录逻辑：
  - 明确 Light 参数应来自“实际放置到场景中的灯光实例”，而不是当前 UI 面板的默认灯光参数。
  - 现有 `SceneObjectRecord` 已包含 `lightPreset`、`colorTemperature`、`lightIntensity`、`lightRadius`，放置 Light 时会保存当时参数快照。
  - `PromptService.makePrompt` 改为接收 `lightRecords`。
  - 没有放置 Light 时，Prompt 使用 `natural ambient lighting`，避免凭空写入默认 `Key Left 45 / 5600K`。
  - 放置 1 盏 Light 时，Prompt 使用该灯的方向、色温、强度和 spread 生成描述。
  - 放置多盏 Light 时，Prompt 生成 `multi-light cinematic setup...` 类型的汇总描述。
  - Lookbook 的 `Light` 字段改为保存汇总字符串：
    - `None`
    - `1 light · Key Left 45 · 5600K`
    - `3 lights · Key Left 45, Rim Right Back, Top Light`
  - 详细多灯参数继续通过 `layoutJSON` 保存，不新增 SwiftData schema，避免迁移风险。
- 修正 Lookbook 灯光 metadata 展示：
  - Lookbook 详情页现在会从 `layoutJSON` 解码实际 `SceneObjectRecord`。
  - 没有放置 Light 时，只显示 `Light: None`，不再显示 `Color / Intensity / Spread`。
  - 只有 1 盏 Light 时，才显示该灯记录中的 `Color / Intensity / Spread`。
  - 多灯时显示 `Light Detail: N saved in layout`，避免把单一全局参数误认为所有灯的参数。
- 讨论顶部 status 调节按钮的去留：
  - 当前顶部 `slider.horizontal.3` 仍会打开旧高级面板，其中包含 `Look` 滤镜和部分老式参数入口。
  - 由于主界面右侧快捷控制已经覆盖了大部分功能，不建议长期保留“泛调节”含义的按钮。
  - 更合理的下一步是将其改造成明确的 `Look` / `Settings` 入口，或把 `Look` 纳入右侧模式调节后删除该按钮。
- 实施新的调节按钮分工：
  - 取景框线 `Frame Line` 保持常驻显示，不提供关闭开关，因为它代表最终裁切边界。
  - `Composition Guides` 明确为构图辅助线，包括三分线、中心十字和安全框，可开关，但不改变最终裁切边界。
  - 顶部原 `slider.horizontal.3` 按钮改为 `Composition Guides` 开关，图标使用 `grid.circle / grid.circle.fill`。
  - 右侧控制栏新增 `Look` 模式，用于调节最终参考图的视觉风格。
  - `Look` 模式提供 `Filter` 调节按钮，左侧内联胶囊显示 `Realistic / Teal Orange / Neon Night / Noir Gold`。
  - 右侧 `Frame` 模式移除 `Guides`，只保留 `Frame / Lens / Shot`，避免把显示辅助开关混入创作参数。
  - Lookbook 保存图不再保存辅助线，只保存取景框裁切后的干净参考图。
- 进一步收束主界面控制：
  - 移除旧 `ControlPanelView`，避免顶部状态区继续保留重复的高级调节面板。
  - 删除 `isControlPanelVisible`、`showControls`、`hideControls` 和旧面板高度逻辑。
  - 撤回独立 `Look` 模式，避免右侧模式数量过多。
  - 将 `Filter` 合并到 `Frame` 模式中，右侧 `Frame` 现在包含 `Frame / Lens / Shot / Filter`。
  - `Subject / Prop / Frame / Light` 四个主模式保持稳定；`Look` 作为 Frame 的视觉输出参数处理。

## 关键实现

- 涉及文件：
  - `SceneZero/SceneZero/Assets3D/Human.usdz`

- 核心逻辑：
  - 文件名与 `AssetPreset.bundleModelName` 对齐。
  - `ARSceneController` 现有加载逻辑会先尝试 bundle 中的 `.usdz`。
  - 如果 `.usdz` 加载失败，仍会回退到几何组合模型。
  - `alignBundledModelToGround` 负责将加载后的模型按 visual bounds 自动贴地。
  - `AdjustmentButtonColumn` 取代原本横向展开胶囊，负责显示功能按钮和垂直参数面板。
  - `AdjustmentParameterPanel` 使用 `LazyVGrid` 直接展示所有参数选项，`Intensity / Spread` 使用垂直滑杆区域。
  - `cameraControls` 从底部 `HStack` 改为右侧 `VStack`。
  - `ToolModePicker` 从横向滑动改为竖向滑动，拖拽方向由 `translation.width` 改为 `translation.height`。
  - `cameraControls` 进一步改为右侧 `ZStack` 分层定位，用固定中线放置 `ShutterButton`。
  - `AdjustmentButtonColumn` 的按钮容器从 `LazyVGrid` 改为 `VStack`，保证所有模式下都纵向排列。
  - `AdjustmentParameterPanel` 的上方浮窗交互被移除。
  - 新增 `InlineAdjustmentBar`，把当前调节项的参数放在对应按钮左侧。
  - `ToolModePicker` 的 `itemSize`、`itemSpacing` 和固定选择位尺寸整体增大，并将未选中颜色改为 `.white.opacity(0.74)`。
  - 新增 `adjustmentButtonColumnHeight` 与 `adjustmentColumnOffset`，用固定快门中线反推调节按钮列位置。
  - 新增 `FramingSafeInsets`，并扩展 `FramingGeometry.frameRect` 支持常驻 UI 安全区。
  - `FramingOverlayService` 新增 `croppedReferenceImage`、`crop` 和 `drawReferenceGuides`，用于输出取景框内参考图。
  - `MainView.captureAndSave` 现在传入当前 `viewportSize` 和 `framingInsets`，保证屏幕取景框与保存裁切一致。
  - `PromptService` 新增 `lightSummary(for:)`、`lightRecords(from:)`、`lightPromptText(for:)`。
  - `ARSceneController.capture` 使用 `PromptService.lightRecords(from: records)` 生成 Prompt。
  - `MainView` 保存 Lookbook 时使用 `PromptService.lightSummary(for: captured.layoutRecords)`，不再直接保存当前全局 `lightPreset.rawValue`。
  - `LookbookView` 详情页新增 `lightRecords(for:)`，根据实际灯光数量决定是否展示 `Color / Intensity / Spread`。
  - `SceneTool` 新增 `.look`，图标为 `camera.filters`。
  - `CaptureAdjustment` 新增 `.filter`，并从 `.frame` 的调节项中移除 `.guides`。
  - `ARSceneController` 将 `.look` 视为非空间放置工具，点击 AR 画面时不生成实体。
  - `MainView.topBar` 的顶部按钮改为直接切换 `controller.showsCompositionGuides`。
  - 后续根据体验反馈移除了 `.look`，并将 `.filter` 移入 `.frame` 的调节项。
  - 删除 `SceneZero/SceneZero/Views/ControlPanelView.swift`。
