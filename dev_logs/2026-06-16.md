## 今日完成

- 新增 4 个轻量 `.usdz` 白模资产：
  - `Human.usdz`
  - `Chair.usdz`
  - `Table.usdz`
  - `Sofa.usdz`
- 资产放置位置：
  - `SceneZero/SceneZero/Assets3D/`
- 资产特征：
  - 使用低面数 USD primitives 生成。
  - 无复杂贴图、无动画、无外部依赖。
  - 文件体积极小，适合课程演示和加载管线验证。
- 清理生成中间文件：
  - `.usda` 源文件仅用于生成 `.usdz`，最终未保留在 app bundle 中。
- 修复 `.usdz` 模型放置后可能漂浮的问题：
  - 加载 bundle 模型后读取 `visualBounds(relativeTo:)`。
  - 根据模型自身 bounds 的 `min.y` 自动把模型底部对齐到 proxy 的地面线。
  - 该修正不依赖当前 4 个极简白模的固定尺寸，后续替换更专业 `.usdz` 时也能继续生效。
- 调整底部 UI 交互：
  - `Subject / Prop / Frame / Light` 模式滑动选择器的固定选择位改为透明描边，不再使用带阴影的玻璃胶囊底座。
  - 当前模式的具体功能按钮始终全部显示。
  - 功能按钮在窄屏下自动排列为 2 列，宽屏下尽量一行显示。
  - 点击某个功能按钮后，不再使用固定长度横向滑动胶囊。
  - 改为在垂直方向展开参数面板，直接显示所有可选参数按钮或对应滑杆。
- 进一步调整主拍摄 UI 的空间位置：
  - 横屏和竖屏都将 `Capture`、模式选择器、当前模式调节按钮放到屏幕右侧。
  - 移除主控制区对底部栏的依赖，避免竖屏压缩 AR 画面、横屏遮挡画面下半部分。
  - `Subject / Prop / Frame / Light` 模式选择器改为竖向滑动，固定选择位仍保持透明描边。
  - 右侧控制列按屏幕尺寸限制宽度和高度，iPhone 与 iPad 共用同一套布局策略。
- 修正右侧控制列的层级与排列：
  - `Capture` 快门按钮固定在右侧垂直中线，不再受上方参数面板高度影响。
  - 当前模式调节按钮改为真正的纵向排列，不再由 `LazyVGrid` 按宽度自动铺成横排。
  - 调节按钮放在右上区域，模式选择器放在快门下方，避免三组控件互相挤压。
- 继续 Apple Camera 化右侧控制 UI：
  - 未选中的 `Subject / Prop / Frame / Light` 模式图标改为白色半透明显示，提升在 AR 暗色/复杂画面上的可读性。
  - 模式选择图标从 38pt 增大到 44pt，固定选择位从 50pt 增大到 56pt。
  - 当前模式调节按钮从 38pt 增大到 44pt，图标字号从 15pt 增大到 17pt，触控面积更接近 iOS 常见 44pt 标准。
  - 删除调节按钮列下方的整组玻璃胶囊底层，只保留每个圆形按钮自身的玻璃样式，降低视觉密度。
  - 将 `Capture` 与下方模式选择器的间距改为固定 18pt，减少横竖屏切换时的视觉漂移。
  - 点击调节按钮后，不再在按钮上方出现独立浮窗。
  - 新增按钮左侧内联参数胶囊栏：点击哪个调节按钮，就在该按钮左侧展开对应的选项或滑杆。
  - `Asset / Frame / Lens / Shot / Direction / Color` 使用横向胶囊选项；`Intensity / Spread` 使用内联百分比 + 短滑杆。
- 缩小右侧调节按钮与 `Capture` 快门之间的距离：
  - 调节按钮列不再固定贴近右上角。
  - 改为按按钮列高度计算位置，让按钮列底部贴近快门上缘。
  - 上方调节按钮与快门的默认间距统一为 18pt，和下方模式选择器与快门的间距保持一致。
  - 横屏高度不足时保留顶部保护距离，避免按钮与状态栏/顶部状态胶囊重叠。
- 微调右侧控件的对齐和间距：
  - 修正调节按钮列圆心相对 `Capture` 和模式选择器偏右的问题。
  - 调节按钮列现在使用 `(shutterSize - adjustmentButtonSize) / 2` 做右侧补偿，与快门圆心对齐。
  - 上方调节按钮与快门的间距从 18pt 增大到 30pt，让右侧控制列呼吸感更好。
  - 下方模式选择器与快门仍保持 18pt，维持相机式模式切换的紧凑感。

## 关键实现

- 涉及文件：
  - `SceneZero/SceneZero/Assets3D/Human.usdz`
  - `SceneZero/SceneZero/Assets3D/Chair.usdz`
  - `SceneZero/SceneZero/Assets3D/Table.usdz`
  - `SceneZero/SceneZero/Assets3D/Sofa.usdz`
  - `SceneZero/SceneZero/Assets3D/README.md`
  - `SceneZero/SceneZero/Views/MainView.swift`
- 核心逻辑：
  - 文件名与 `AssetPreset.bundleModelName` 对齐。
  - `ARSceneController` 现有加载逻辑会先尝试 bundle 中的 `.usdz`。
  - 如果 `.usdz` 加载失败，仍会回退到几何组合模型。
  - `alignBundledModelToGround` 负责将加载后的模型按 visual bounds 自动贴地。
  - `AdjustmentButtonColumn` 取代原本横向展开胶囊，负责显示功能按钮和垂直参数面板。
  - `AdjustmentParameterPanel` 使用 `LazyVGrid` 直接展示所有参数选项，`Intensity / Spread` 使用垂直滑杆区域。
  - `cameraControls` 从底部 `HStack` 改为右侧 `VStack`。
  - `ToolModePicker` 从横向滑动改为竖向滑动，拖拽方向由 `translation.width` 改为 `translation.height`。
  - `cameraControls` 进一步改为右侧 `ZStack` 分层定位，用固定中线放置 `ShutterButton`。
  - `AdjustmentButtonColumn` 的按钮容器从 `LazyVGrid` 改为 `VStack`，保证所有模式下都纵向排列。
  - `AdjustmentParameterPanel` 的上方浮窗交互被移除。
  - 新增 `InlineAdjustmentBar`，把当前调节项的参数放在对应按钮左侧。
  - `ToolModePicker` 的 `itemSize`、`itemSpacing` 和固定选择位尺寸整体增大，并将未选中颜色改为 `.white.opacity(0.74)`。
  - 新增 `adjustmentButtonColumnHeight` 与 `adjustmentColumnOffset`，用固定快门中线反推调节按钮列位置。
