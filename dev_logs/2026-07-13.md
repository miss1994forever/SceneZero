# SceneZeroV2 开发日志

## 基本信息

- 日期：2026-07-13
- 范围：仅 `SceneZero/SceneZeroV2`
- 主题：灵感媒体入口、录音可靠性、原生播放与录音 UI

## 已完成

### 录音与播放

- 修复 `AVAudioRecorder.stop()` 后 `currentTime` 可能回到 `0` 的问题：停止前快照录音器时长，并以经过时间作为兜底，保存的声音灵感不再写入 `0:00`。
- 录音使用原生 `AVAudioRecorder` 写入 AAC/M4A，保存前复制到 `Application Support/InspirationMedia/audio`。
- 新增 `AudioPlaybackController`，以原生 `AVPlayer` 实现：
  - 周期性更新实际播放进度；
  - 显示“已播放 / 总时长”和进度条；
  - 收到播放结束通知后恢复播放按钮；
  - 页面离开时暂停、归零并清理观察器。
- 本地音乐导入继续使用 SwiftUI 原生 `fileImporter`；没有引入第三方录音或播放框架。

### 灵感媒体入口与弹窗

- 顶部图库入口合并照片和视频选择，使用 `PhotosPicker` 的 `.images + .videos` 匹配规则。
- 移除添加菜单内嵌且在部分场景无法触发的视频入口；用户可从图库按钮直接导入视频。
- 音乐来源窗口移除单独的半屏 detent，恢复与文字、录音一致的标准 sheet 呈现。

### 录音 UI 迭代

- 开始/停止按钮改为显式 `Image + Text` 内容，强制白色麦克风/停止图标，避免 `.borderedProminent` 与 `Label` 在 Form 中未稳定显示图标的情况。
- 删除“准备开始”和“正在录音”冗余文案，录音状态由时长、红色停止按钮与停止符号共同表达。
- 录音中在按钮下方加入灰色滚动时间线：最新音量采样从右侧进入，超过 46 个采样后最旧采样从左侧移除。
- 波形使用 `updateMeters()` 与 `averagePower(forChannel:)` 的实际输入电平，不使用随机动画；“减少动态效果”开启时保留低位静态表现。

## 设计评审结论

- 参考 Apple Voice Memos：录音中以波形、时间和主控制表达状态，避免在同一焦点区重复加入状态文案；回放阶段再将波形发展为可定位的时间线。
- SceneZero 保持轻量创作记录定位，不直接引入 Ferrite 一类面向播客/新闻制作的多轨编辑工作流。
- 后续优先级：
  1. 将当前滚动波形的密度调整为约 28–32 根较高圆角柱，增强可读性；
  2. 为录音加入暂停/继续，停止则进入预听与保存；
  3. 保存录音后保留波形缩略图，并在详情页支持拖动定位播放。

## 2026-07-13 V2 迭代 1：场景事实与本地结构化 Prompt

### 已完成

- 新增纯 Swift、可编码的领域模型：`SceneSnapshot`、`CameraSnapshot`、`SceneEntitySnapshot`、`LightingSnapshot`、`CreatorIntent` 与 `PromptDraft`。
- 快门触发时同步冻结 AR 场景：相机世界变换、每个已放置实体的世界位置、相机坐标、朝向、尺寸、镜头设置与逐灯参数；RealityKit 异步截图完成后不会重新读取变化中的控制器状态。
- 新增 `SpatialRelationResolver`，集中定义画面左/中/右、前/中/后景和人物面对/背对/侧向镜头的阈值；本地编译器只使用这些事实和用户明确输入，不再自动加入“生活痕迹”“故事感”等无依据文案。
- 新增 `PromptRenderer`：通用、Sora、Runway、可灵导出均由同一份 `PromptDraft` 派生，平台格式不再各自重新拼接事实。
- 取景保存链现在同时创建：
  - `ARPrevisualization.layoutData`：编码的 `SceneSnapshot`；
  - `PromptDocument.structuredData`：编码的 `PromptDraft`；
  - `PromptDocument.canonicalText`：当前通用可复制 Prompt；
  - `Inspiration.prompt` 与 `layoutJSON`：兼容投影。
- 灵感详情优先读取新 `PromptDocument`；旧条目或解码失败仍回退兼容字段。展开“查看全部字段”会显示字段来源（现场 / 用户 / 待确认）。编辑“我当时想到”时会重新编译并同步更新 PromptDocument 与兼容文本。

### 本轮未做、原因与后续方案

- 未伪造 `SceneZeroSchemaV2` 的 SwiftData 轻量迁移。当前仓库只保留了一份已建模的 V1 模型类型；SwiftData 的正式版本迁移必须先冻结可运行的历史 V1 模型快照，再创建独立 V2 模型命名空间，不能把同一批 `@Model` 类型同时声明为两个 Schema。下一步先补历史 Schema 快照和一次幂等 backfill，再切换 App 的 migration plan。
- `CollectionMembership` 的浏览、移动、排序、重命名尚未替换 `boardName/sortIndex` 兼容字段；它需要作为独立 P0 数据一致性改动，避免与本轮 AR 事实链相互混杂。
- 未接入模型后端；本地 `LocalPromptCompiler` 是无网和 API 失败时的完整可用基础。

## 2026-07-13 V2 数据一致性：Iteration 1 后修订方案

### 已完成

- 采用讨论记录中的路径 A：V2 开发数据可清空，不人为创建 SwiftData Schema V2。`SceneZeroSchemaV1` 被标记为首个冻结基线；App 改用 `Application Support/SceneZeroV2/SceneZeroV2-V1.store` 作为新的显式开发 store，旧的隐式开发 store 不会被载入。
- 新增内容版本解码器：`SceneSnapshotDecoder` 与 `PromptDraftDecoder` 先读取 `schemaVersion`，再按已知版本解码。缺版本、损坏、未知版本或 `PromptDocument.schemaVersion` 不一致都会返回可读错误，不再静默 `try?` 回退为空数据。
- `PromptDocument` 成为优先事实来源：详情页若结构化 blob 无法读取，会明确显示“使用兼容文本”及原因，并直接展示/复制 `canonicalText`；不会把损坏数据伪装成正常结构化 Prompt。
- 图片、视频、文字、声音和音乐等新灵感都会创建初始 `PromptDocument`；没有 AR 快照的条目只记录明确已知的地点/用户备注，并把未确定字段写入 `uncertainties`。
- 灵感集改由 `CollectionMembership` 读取和排序：
  - “所有灵感”与“收藏”保持查询结果，不建立伪 membership；
  - 同一灵感可加入多个自定义灵感集；
  - 灵感集卡片、详情页 membership 菜单、重命名和排序均不再以 `Inspiration.boardName/sortIndex` 作为读取事实；
  - `InspirationCollectionService` 提供 add/remove/replace/reorder/rename/delete/backfill 等集中操作；
  - legacy `boardName` 的一次性幂等 backfill 通过 `UserDefaults` 版本标记短路，重复进入灵感页不会重复建关系。
- 详情页的“我当时想到”改为 350ms 可取消的内存预览；失焦、键盘“完成”或页面离开时才写入 SwiftData。保存失败会保留草稿并显示错误。

### 本轮未做

- 未添加 V2 专用 unit-test target：现有 `SceneZeroTests` 绑定旧 target，直接改用会破坏旧 Demo 测试。下一步应建立独立 `SceneZeroV2Tests` target，并加入 membership backfill、多集归属、内容版本 fixture 和 debounce 回归测试。
- 尚未实现 Iteration 2 的 `LocalCreativeAdvisor`、建议 UI 与录音收尾；这些属于“数据一致性”完成后的下一轮。
- 当前 V1 的 `@Model` 类型仍是全局类型，冻结约定通过代码注释和开发流程维持；在第一次真实持久化属性变更前，应将历史模型复制进独立 VersionedSchema 命名空间，形成可编译强制的历史快照。

## 2026-07-13 V2 Iteration 2：真实本地创作建议

### 已完成

- 新增纯 Swift `LocalCreativeAdvisor` 与 `CreativeSuggestion`。引擎只读取 `SceneSnapshot + CreatorIntent`，不上传或分析完整参考图，输出稳定排序的可解释建议。
- 首批实现 11 条确定性规则：AR tracking 未稳定、无角色时环境主体、角色同侧集中、角色与道具关系不清、85mm 狭小空间、24mm 近拍、正面单灯、无补光轮廓光、多方向混光、疏离意图与角色过近、压迫意图与广角深空间冲突。
- 每条建议包含观察、建议、理由、来源、本地探索等级和可选安全 action。自动 action 严格限定为切换焦距、景别或灯光强度；涉及位置、朝向或数量的建议只提示用户手动处理，不会移动 AR 实体。
- `ARSceneController` 新增非拍摄 `currentSceneSnapshot()` 和受限 `apply(_:)`。同时修复灯光参数只更新 RealityKit 而未回写 `SceneObjectRecord` 的问题，使实时建议与快门保存的事实快照一致。
- 取景页替换原有三条硬编码“创作建议”文案：场景版本变化后以 650ms 可取消 debounce 计算，默认显示一条主建议；灯泡打开原生 sheet，最多提供三条候选和“应用 / 换一个 / 忽略”。VoiceOver 按“观察、建议、原因、动作”的顺序播报。
- RealityKit 直接手势（拖拽、旋转、缩放）使用 `SceneEvents.Update` 的阈值观察：移动达到约 2cm、缩放达到约 2%、旋转达到约 3° 才更新场景版本；因此不会逐帧运行建议引擎。
- 新增本地反馈存储，仅保存 `ruleID + applied/swapped/ignored + 时间`，最多 100 条；不保存图像或完整场景快照。
