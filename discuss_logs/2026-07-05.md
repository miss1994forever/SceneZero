## Conclusions

- The previous positioning, "mobile AR location-scouting and visual Prompt generation tool," is differentiated but too narrow if treated as the entire product.
- Structured Prompt generation should be treated as a translation layer, not a feature that only works after AR capture.
- AR should become one high-value capture/previsualization mode inside a broader visual reference workflow.
- Lookbook should not be framed as a storyboard. It is better framed as an AI video reference board: each item is an image plus shot language, scene tags, spatial notes, lighting notes, and Prompt metadata.
- The demand is not fake, but the product must avoid becoming only an "AR model placement toy." The real pain point is the gap between messy visual inspiration and controllable AI video input.
- Recent AI video tools show a clear movement toward reference-driven generation, continuity, shot control, scene editing, and multi-input workflows. This supports SceneZero's broader direction.
- AI short drama teams should not be treated as primary users. Their production logic is often fast-cycle, traffic-driven, and efficiency-first, which conflicts with a tool built around long-term visual accumulation and on-site discovery.
- SceneZero is better positioned for author-driven AI filmmaking: student directors, independent short-film creators, experimental image makers, and long-form film development.
- Long-term inspiration collection is not a weakness. For personal, emotional, or author-driven films, ideas may emerge years before production, and a persistent visual notebook can become valuable.
- Real location discovery is a meaningful differentiator because many emotionally resonant shots are found on site through light, texture, distance, and chance composition, not fully planned in advance.
- SceneZero does not need to implement AI video generation inside the app at the current stage. It can focus on preparing the reference package and transformation intent for external tools.
- A natural-language "AI Brief" feature fits the product very well: users can write a loose scene idea, and the app helps organize it into structured fields such as scene base, emotion, keep/change intent, shot language, genre direction, and Prompt draft.
- This feature turns SceneZero from a reference-image collector into a creative-intent organizer.
- The safest social model is layered visibility: private by default, invite-only project collaboration second, public square only as an opt-in outer layer.
- A public square should not use likes, rankings, follower counts, or recommendation-feed logic.
- If public interaction exists, "save" should be separated from "respond" and "reference":
  - Save: low-friction personal revisit, ideally without public counts.
  - Respond: a visible creative reply or resonance note.
  - Reference: a formal attributed use of another public reference in one's own project.
- Private saves can feel like silent extraction. For an author-driven inspiration tool, this is a real trust issue.
- Even with "view only" permissions, users can screenshot or photograph public references, so permission design cannot fully prevent idea leakage.
- For the current competition/product positioning, a fully private + invite-only collaboration model is more coherent and safer than launching a public square as a core feature.
- A public discovery layer may still be valuable in a larger AI filmmaking ecosystem, but should be framed as a later opt-in experiment rather than the first product promise.

## Product / Design Direction

- Reposition SceneZero as:
  - "面向作者型 AI 影像创作者的长期视觉灵感与场景参考工作台"
  - "Long-term visual inspiration and scene reference workspace for author-driven AI filmmakers"
- New product sentence:
  - SceneZero helps users capture, organize, previsualize, and translate visual inspiration from real locations, personal photos, and reference images into reusable AI video reference packages.
- Recommended workflow:
  1. Capture inspiration from real spaces, photos, or imported references.
  2. Organize references into boards by project, scene, mood, location, or shot type.
  3. Add shot metadata such as frame ratio, lens language, camera angle, lighting, color, subject placement, and notes.
  4. Use AR or 2.5D staging to add characters, props, or light markers when spatial planning is needed.
  5. Generate structured prompts and reference packages for downstream AI video tools.
- AR is now a signature capability, not the product boundary.
- Real-scene capture remains valuable because it can preserve unexpected composition, texture, natural light, local atmosphere, and lived-in detail that pure virtual staging may miss.
- The product should emphasize "saving and developing visual memory" rather than "rapidly producing short videos."
- Fast AI short drama production can remain an adjacent scenario, but should not define the core product narrative.
- Add an "AI Brief / 生成简报" layer to each reference package. It records what the user wants to preserve from the initial reference and how they want AI tools to transform it.
- The recommended loop becomes:
  1. Capture or import a reference image.
  2. Add AR / 2.5D staging if spatial planning is needed.
  3. Write a freeform scene idea.
  4. Let the app organize it into a structured Reference Package.
  5. Copy/export the structured Prompt to Runway / Kling / Veo / Luma or other AI video tools.
- Social/visibility direction:
  - MVP: private local workspace.
  - Near term: invite-only project collaboration and share/export links.
  - Later: optional public discovery only after trust, attribution, moderation, and permission design are mature.
- If public discovery is explored later, it should prioritize search by mood, scene type, light, memory, and shot language, not popularity.

## Technical Notes

- Short-term feasible additions:
  - Import photos from local album.
  - Save imported images into Lookbook boards.
  - Add manual tags: location, mood, shot type, lighting, color, character count, usage.
  - Generate structured Prompt from both AR captures and imported references.
  - Add a 2D annotation/staging layer over imported images: frame lines, subject markers, arrows, light direction, notes.
  - Add a freeform "scene idea" text field for each reference.
  - Generate a structured AI Brief from that text field using a deterministic template first.
- Medium-term feasible additions:
  - Reference analysis using an external or local vision model: scene type, composition, lighting direction, color palette, shot scale.
  - Reference board export for Runway / Kling / Veo / Luma-style workflows.
  - Project-level boards: Reference, Location, Character, Shot Ideas, Generated Results.
  - Use an LLM to extract structured fields from freeform user notes:
    - Scene Base
    - Story Intent
    - Keep From Reference
    - Transform Direction
    - Shot Language
    - Mood / Emotion
    - Negative Constraints
    - Prompt Draft
- High-risk future directions:
  - True single-photo 3D scene reconstruction.
  - Gaussian Splatting / NeRF scene editing.
  - Accurate depth-aware object insertion into arbitrary photos.
  - Automated movie-still search with copyrighted content.
- Safer wording for competition:
  - "2.5D reference staging from photos" instead of "reconstruct 3D scene from a photo."
  - "user-imported film stills / authorized reference images" instead of "search existing movie screenshots."

## Industry Notes

- Runway Gen-4 emphasizes consistent characters, locations, objects, visual references, and multi-angle scene coverage.
- Runway Aleph emphasizes in-context video editing, including adding/removing objects, changing style and lighting, and generating new angles.
- Google Flow / Veo 3.1 emphasizes reference-image-based "Ingredients to Video," first/last-frame control, scene extension, insert/remove editing, and more narrative control.
- Luma Ray3.2 emphasizes multi-keyframe control, camera motion transfer, video modification, relighting, environment change, and production pipeline formats.
- Research such as SkyReels-A2 frames "elements-to-video" as a controllable generation task that preserves characters, objects, and backgrounds from reference images.
- These directions suggest that AI video production is moving toward controllable reference packages, not just better text prompts.
